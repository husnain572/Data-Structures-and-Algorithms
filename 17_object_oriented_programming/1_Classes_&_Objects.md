## What is OOP?
 
OOP (Object-Oriented Programming) is a programming paradigm that organizes code around **objects** rather than functions and logic.
 
| Term | Definition |
|------|------------|
| **Object** | A real-world entity (e.g., a car, a student, a user) |
| **Class** | A blueprint/template for creating objects |
| **Attribute/Property** | Data stored inside an object (e.g., name, color) |
| **Method/Member Function** | Behavior/actions of an object (e.g., start(), stop()) |
