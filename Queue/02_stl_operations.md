# Queue STL Operations

## `queue<T>`

```cpp
#include <queue>
queue<int> q;
q.push(x);     // enqueue
q.pop();       // dequeue
q.front();     // peek front
q.empty();     // is queue empty
```

## `deque<T>`

```cpp
#include <deque>
deque<int> dq;
dq.push_back(x);
dq.push_front(x);
dq.pop_back();
dq.pop_front();
```
